# C&C: Napoleonics — Plan 4: UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every Napoleonic decision is playable by a human with good UX (squares and the hidden square track, Retire and Reform, First Strike, Combined Arms, take ground and breakthrough, Élan and Rally dice, Short Supply, Scout, flags), on a screen that no longer looks or reads like Ancients: real die faces, a worded log for every event, the rules reference, Napoleonic ranks and medals for all 33 battles, and basic accessibility.

**Architecture:** The engine (`src/engine`) is a decision generator with a frozen contract (`types.ts`); the UI never changes it. Every human decision goes through the pure `promptSpec(s, d)` (title, text, buttons, hexes) and, for board choosers, pure helpers in `uiModel.ts` / new pure modules (`logText.ts`, `assign.ts`, `squareText.ts`), so nearly all behaviour is unit-tested without a DOM; React components only render those descriptions. Tasks run in three lanes with disjoint files; game-screen tasks start as their Plan 2B engine wave merges.

**Tech Stack:** TypeScript 5.6, React 18, Vite 5, Vitest 2 (`renderToStaticMarkup` for markup tests), the existing kit (`src/ui/kit`), `AiClient` (`src/ai/client.ts`).

**Spec:** `design/superpowers/specs/2026-11-17-cnc-napoleonics-design.md` (phase 5 UI; extras: Triumphs, rules reference; look and feel). Rules: `design/rules-reference.md` (RR) and `design/rulings.md`. Carry list: `.superpowers/sdd/2026-11-17-plan-2b-engine/carry-forward.md` (every "Plan 4" item is placed in a task below).

## Review Focus

1. **The general's answer arrives late.** "Let the general decide" now runs in the worker; the player may press Undo or the decision may change before it returns. Expected: a stale answer is dropped, never applied to another decision. Pinned in Task 3 (`auto-answer.test.ts`, "a stale answer is dropped").
2. **Hidden cards leak.** The AI's square-track cards and the Scout's two cards must not reach the DOM, the log or an `aria-label`. Pinned in Task 6 ("the opponent's track shows backs only") and Task 4 ("Scout cards are shown only to their owner") and Task 3 ("squareFormed names no card").
3. **Élan or Rally with dice that can do nothing** (all sabres, every unit at full strength, a flag with no piece left). Expected: those dice show "no effect", Confirm stays enabled with `null`s, the player is never stuck. Pinned in Task 4.
4. **A selection that outlives its decision** (guns toggled, a die armed, then the decision changes or an id is no longer an option). Expected: the board marks and Confirm use only ids in the current decision's options. Pinned in Task 7 and Task 4.
5. **The flipped board** (human commands the top army): square counters, retire previews, objective markers and paths must turn with the board. Pinned in Task 6 ("the square counter sits on its unit on a flipped board") and Task 5 ("a flipped board previews the same path").
