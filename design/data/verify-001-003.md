# Battles 001-003 verification (independent, Opus)

Verifier: independent Opus reviewer, 2026-11-17. Files checked (commit 8c80691, branch `maps-a`): `design/data/001.json`,
`002.json`, `003.json` and `notes-001-003.md`. No data file was edited.

**Result: all 3 battles match the maps. 0 discrepancies.** The two places where the data departs from the survey
(001 forest 8, 003 hill 18) follow the map, and the map is right in both. The "(unnamed)" French leaders are correct:
the map has no name on those blocks.

## Method

- **Read the map first.** Each map (`cnc-napoleonics-research/maps/NNN.jpg`) was read hex by hex from its own grid crops
  before the data file was compared: every block (side colour, code label, stack), every terrain hex, objective outlines
  and town labels. The independent reading was then compared with the JSON entry by entry.
- **Grid.** Each file's `grid` equals the map's fit in `scripts/maps/grids.json` (001 and 003: 72.38/72.25, 132.38;
  002: 74.38, 130.38; w 87, pitch 75.5). The grid lines in the crops sit on the printed hex outlines on all three maps.
- **Renders.** `render.py` drew each file over its map (`map-work/verify-001-003/r00N.png/`). Compared at full size:
  every unit tag, leader tag, terrain letter and objective outline sits on the map feature it names.
- **Crops.** `crops.py --scale 2.5` with grid and r,c labels over the whole board of each map, in nine blocks of 3 rows ×
  5 columns (`map-work/verify-001-003/crops00N/`). Every river, hill, rugged hex, forest, town, objective and unit
  cluster was looked at in these. Extra 4-6× zooms of single hexes (`z00N_*.png`) for the stacks with second blocks, the
  forest at 001 2,3, and the hills under blocks on 003.
- **Block counts by eye** per side and per code on each map, compared with the JSON and the survey matrix.
- **check.py**: `ok` for all three files.
- **scan.py**: 001 0 flags. 002 flags 3,8 5,0 5,8 (hill 0.12, data none). 003 flags 2,8 3,7 6,8 (hill 0.13, data none).
  All six are rugged hexes in the data, and the crops show stones on all six: the rugged art carries rays too, so these
  are false flags, as the notes say. `scan.py --dump` was also read for every hex: on all three maps the data's hills
  score 0.13-0.21 and every other non-rugged hex scores 0.00-0.05, so no hill is missing or extra; forests score
  0.21-0.29 and nothing else above 0.05; water is above 0.02 only on the data's river hexes.
