# Battles 013–015 verification (independent, Opus)

Verifier: independent Opus pass, 2026-11-17. Files checked at commit 1985adf (branch maps-a): `design/data/013.json`,
`014.json`, `015.json` and `notes-013-015.md`. No data file was edited.

**Result: all 3 battles match the maps and the survey. 0 discrepancies.** The transcriber's doubts (015 Reille label,
014 La Thile, hills under blocks in 014 and 015, the 013 ford) are settled below; each one holds.

## Method

- **Independent reading first.** Each map (`cnc-napoleonics-research/maps/NNN.jpg`) was drawn with its fitted grid and
  `r,c` labels (`overlay.py`, per-map fit from `grids.json`: 013 (72.38, 132.5), 014 (72.38, 132.38), 015 (74.12,
  136.12), w 87, pitch 75.5; each data file's `grid` equals these). Units, leaders and terrain were read hex by hex from the
  overlay and from 2× crops of six regions per map (`crops.py`), then compared with the data dump.
- **Zoom crops** (3.5–5×, own crop script with grid) of every doubtful hex. Hill rays under blocks were checked on a
  contrast-stretched green channel, with a control hex (015 1,9, a stack on plain ground: no rays at all) to make sure the
  rays are not block shadow. Leader labels were read at 8×.
- **Block colours** were checked in the crops for every top unit: red frame = BR, brown frame = PT (013) or AL (014,
  015). The red band at the foot of artillery blocks is the unit-type label, not the frame.
- **Renders** (`render.py`) of each data file over its map were compared at full size: every tag sits on its block or
  terrain tile.
- **Tools:** `check.py` ok on all three. `scan.py`: 013 one flag (2,8 river 0.01), 014 none, 015 four hill flags (2,8 6,5
  6,8 6,9, 0.10–0.11). All flags were looked at in zoom crops; none is an error (see below).
- **Counts** were made by hand from the map, not from the file, and agree with the file and with survey 2.1.
- Images: `cnc-napoleonics-research/map-work/verify-013-015/` (overlays `NNN.png`, crops `NNN_r*_c*.png`, zooms `z*.png`,
  enhanced `*_enh.png`, labels `lbl_*.png`, renders `render-NNN.png/`).
